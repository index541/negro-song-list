曲リスト管理

このページは堅斗専用です。曲の追加・編集・削除には、堅斗の GitHub トークンが必要です。公開ページを見るだけの人は、ここで何も変更できません。

1. トークンの設定（最初に1回だけ）

GitHub の「このリポジトリ専用」トークンを貼ると、このブラウザから曲を保存できるようになります。トークンはこのブラウザの中にだけ保存されて、ページやリポジトリには入りません。

トークンの作り方
  1. GitHub の設定から「Fine-grained tokens」の新規作成を開く（github.com/settings/personal-access-tokens/new）
  2. Token name は何でもOK（例：song-list）。有効期限は長めでOK
  3. Repository access で「Only select repositories」を選び、negro-song-list だけを選ぶ
  4. Permissions の Repository permissions で Contents を「Read and write」にする
  5. 「Generate token」で発行して、表示された文字列をここに貼る

2. ジャケットを探す

曲名（できればアーティスト名も）を入れて探すと、候補のジャケットが出ます。気に入ったものを押すと、下の編集フォームに反映されます。

3. 曲の編集

保存すると公開ページに反映されます（反映まで1分ほどかかります）。
