曲リスト管理

このページは堅斗専用です。曲の追加・編集・削除には、堅斗の GitHub トークンが必要です。公開ページを見るだけの人は、ここで何も変更できません。

人に読み取ってもらうと、公開リストが開きます。

公開リストのQRコード

https://index541.github.io/negro-song-list/

1. トークンの設定（最初に1回だけ）

GitHub の「このリポジトリ専用」トークンを貼ると、このブラウザから曲を保存できるようになります。トークンはこのブラウザの中にだけ保存されて、ページやリポジトリには入りません。

トークンの作り方
  1. GitHub の設定から「Fine-grained tokens」の新規作成を開く（github.com/settings/personal-access-tokens/new）
  2. Token name は何でもOK（例：song-list）。有効期限は長めでOK
  3. Repository access で「Only select repositories」を選び、negro-song-list だけを選ぶ
  4. Permissions の Repository permissions で Contents を「Read and write」にする
  5. 「Generate token」で発行して、表示された文字列をここに貼る

2. ジャケットを探す

曲名（できればアーティスト名も）を入れて探すと、候補のジャケットが出ます。気に入ったものを押すと、ジャケットと一緒に曲名・アーティスト名、取れる場合はジャンルまで下の編集フォームに入ります。

3. 曲の編集

保存すると公開ページに反映されます（反映まで1分ほどかかります）。

五十音順の並びと見出しに使われます。自動の読みが違う時だけ直してください。空欄なら自動判定になります。

アーティスト順の並びに使われます。自動の読みが違う時だけ直してください。空欄なら自動判定になります。

正方形で見える位置は、画像をドラッグして変えられます。

画像ファイルが設定されています。保存すると、選んだ位置で正方形に切り取ってアップロードされます。

画像ファイルは、この編集画面へのドラッグ＆ドロップや貼り付け（Ctrl+V）でも設定できます。画像のURLを落とした時も入ります。

原曲キー

試聴音源（切り出し音源か公式試聴）をキー変更して再生します。＋と−で耳で確かめて、「このキーをキー表示に入れる」を押すと上のキー表示に反映されます（「保存する」を押すまで確定しません）。試聴音源が無い曲では使えません。

開始0:00
終了0:00

スライダーを動かすと秒の欄にも反映されます。動画を再生しながら「今の位置を開始に／終了に」を押すと、その位置がそのまま入ります。「この範囲を再生する」で確かめながら合わせられます。

曲名・アーティスト・よみがな一括設定

曲名・アーティスト名と、その読みをまとめて直すための画面です。各行で直して「変更をまとめて保存」を押すと、1回の保存でまとめて反映されます。曲名とアーティスト名は空にはできません。読みは空欄にすると自動判定に戻り、カタカナで打っても保存の時にひらがなに直ります。各欄では入力すると候補が出て、読みの欄は空欄で押すとその曲やアーティストに紐づく読みの候補が出ます。行のチェックで曲を選んで、下の欄から同じアーティスト名をまとめて設定もできます（表記の統一に便利です）。

作品名一括設定

作品名と、その読みをまとめて直すための画面です。各行で直して「変更をまとめて保存」を押すと、1回の保存でまとめて反映されます。作品名を空欄にすると作品名なしに戻ります。読みを入れておくと、公開ページで作品名の読みからも検索できるようになります。入力すると今ある作品名や読みが候補で出て、作品名を候補から選ぶと、読みが空ならその作品の読みも入ります。行のチェックで曲を選んで、下の欄から同じ作品名や読みをまとめて設定もできます（下の欄は、入れた欄だけが設定されます）。

ジャケット・キー一括設定

ジャケット画像のURLとキーをまとめて直すための画面です。キーはタップで選ぶだけです。各行で直して「変更をまとめて保存」を押すと、1回の保存でまとめて反映されます。ジャケットのURLを変えると、前に合わせた表示位置はリセットされます。サムネイルを押すと、その行で表示位置の調整や、画像ファイルの選択・ドラッグ＆ドロップ・貼り付け（Ctrl+V）ができる欄が開きます。ファイルの画像は、保存のときに選んだ位置で正方形に切り取ってアップロードされます。行のチェックで曲を選んで、下のキーからまとめて設定もできます。

試聴の一括設定

公式試聴（30秒）をまとめて直すための画面です。各行でURLを直したり、「自動で探す」で今の曲名・アーティストから探したり、「外す」で取り除いたりできます。「▶ 聴く」で、その場で音を確認できます。サビ（YouTube）を設定した曲は試聴よりサビが優先されるので、試聴は予備として残ります。

アーティスト表記のゆれ

同じアーティストなのに表記が揺れていそうな候補を自動で探します。揃えたい表記を選んで「この表記に揃える」を押すと、対象の曲すべてに反映されます。別のアーティスト同士が混ざっていたら、そのままにしてください。

最近の変更と取り消し

曲リストへの最近の保存履歴です。「この時点に戻す」を押すと、その時の曲リストに戻せます（戻したことも新しい保存として記録されます）。音源ファイルやジャケット画像そのものは戻りませんが、音源は見回りが自動で作り直します。
